# Приложуха — MVP

Небольшое веб-приложение, которое можно открыть на iPhone по ссылке и добавить на экран «Домой».

## Публикация через GitHub Pages

1. Создай на GitHub новый репозиторий `prilozhuha`.
2. Загрузи в корень репозитория `index.html`, `manifest.webmanifest`, `icon.svg` и `sw.js`.
3. Открой в репозитории **Settings → Pages**.
4. В разделе публикации выбери **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем нажми **Save**.
5. После публикации открой ссылку, которую покажет GitHub Pages. Для репозитория `prilozhuha` она обычно выглядит как `https://<имя-пользователя>.github.io/prilozhuha/`.
6. На iPhone открой эту ссылку в Safari, нажми **Поделиться → На экран «Домой»**.

При обновлении файлов в ветке `main` GitHub Pages опубликует новую версию автоматически.

## Где сохраняются данные

Задачи, цели и операции пока хранятся в локальном хранилище браузера на конкретном устройстве. Они не синхронизируются между телефоном и компьютером и не передаются другу. Для общей учётной записи, базы данных, ИИ или фоновой синхронизации понадобится отдельный серверный сервис.
