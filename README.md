# Приложуха — MVP

**Открыть приложение:** https://luphy609-blip.github.io/priloshuxa/

## Установка на iPhone

1. Открой ссылку выше в Safari.
2. Нажми «Поделиться» → «На экран „Домой“».

После первого открытия приложение может загружаться без сети. Для этого в нём есть кэширование файлов сайта.

## Что важно знать

- GitHub Pages бесплатно размещает эту статическую версию сайта из ветки `main`.
- Задачи, цели и операции сохраняются в браузере конкретного устройства.
- Данные между устройствами и пользователями не синхронизируются.
- Общая база данных, вход для друга, ИИ и синхронизация с МЭШ потребуют отдельного серверного сервиса.
